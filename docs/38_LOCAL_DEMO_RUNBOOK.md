# 38 — Локальный запуск и показ демо LogSklad

## Текущее состояние

Локальная демо-среда проверена 24 сентября 2026 года. Сейчас Next.js доступен по [http://localhost:3001](http://localhost:3001), PostgreSQL Docker слушает `127.0.0.1:5435`. После запуска ориентируйся на адрес из строки `Local` в терминале: если порт занят, Next.js выберет следующий свободный.

## Запуск в Windows PowerShell

1. Убедись, что Docker Desktop запущен.
2. Перейди в папку проекта и подними базу:

```powershell
Set-Location E:\codex\logsklad
docker compose up -d postgres
```

3. Запусти приложение:

```powershell
pnpm dev
```

4. Открой адрес из строки `Local`. Сейчас это `http://localhost:3001`.

Если сервер уже запущен, используй его. Дополнительный процесс на той же папке может занять 3002. Чтобы перезапустить текущий сервер, вернись в его PowerShell-окно, нажми `Ctrl+C` и выполни `pnpm dev` снова.

Файл `.env.local` содержит локальные параметры и секреты; не копируй его в чат, репозиторий или на экран показа.

## Восстановление исходных демо-данных

Сброс нужен только если требуется вернуть seed. Он удалит созданные в локальной демо-базе заявки и локальные загруженные файлы, после чего восстановит исходный набор.

1. Переключись на администратора.
2. Открой `/admin/demo`.
3. Введи точную фразу `ВОССТАНОВИТЬ ДЕМО` и подтверди действие.

Сброс доступен только при `DEMO_MODE=true`; он блокируется в production и выключен в режиме просмотра дизайна. Во время приёмочного прогона сброс не запускался, поэтому текущие принятые заявки сохранены.

## Границы локальной демо-среды

- PostgreSQL и загруженные файлы находятся на этой машине; локальные данные не опубликованы в интернете и не синхронизируются с внешним демо.
- Supabase, Vercel и публичный demo URL не настроены в рамках локальной приёмки.

## Остановка

В окне, где запущен Next.js, нажми `Ctrl+C`. Docker-контейнер базы можно оставить запущенным для следующего показа.
