## Границы локального MVP

- Этот прогон покрывает локальное демо. Vercel, Supabase и публичный URL не настраивались. `.env.local` содержит локальные параметры и секреты; не передавай этот файл и не включай его в артефакты показа.
- Формальная проверка доступности, контраста, всех loading/empty/error-состояний и ошибок загрузки файлов не проходила целиком; соответствующие пункты остаются открытыми в `32_VISUAL_QA.md` и `35_QA_RELEASE_CHECKLIST.md`.
- Полный сквозной прогон всех административных CRUD-операций не выполнялся; страницы справочников открываются, аудит read-only.
- Защита восстановления seed проверена по коду. Сброс не запускался, чтобы не удалить принятые демо-заявки.
- В Flow C и D заявки оставлены в `SUBMITTED`; проведение до `COMPLETED` не требуется для утверждённого показа A/B.

## Критерий готовности этого этапа

Для локального показа критерий достигнут: пять ролей открываются и сохраняются после обновления; сценарии A/B живут в общей PostgreSQL; C/D отображают сохранённые заявки; общая дизайн-система и responsive-матрица приняты; lint, typecheck и production build проходят.

Публичное размещение — самостоятельный следующий этап, потому что для него нужно выбрать и настроить внешнюю инфраструктуру.
